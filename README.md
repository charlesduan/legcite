# Don't Use This Repository!

This repository contains an outdated version of my LaTeX legal citation program.
It exists because it is cited in an
[*amicus curiae* brief](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2405553)
filed in the U.S. Supreme Court.

The current version is [available here](https://github.com/charlesduan/hicite).
If you wish to use or fork this software, please use that one.
